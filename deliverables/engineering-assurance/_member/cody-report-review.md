# Code Review：LOS24 卡开机动画静态分析报告（作为「逻辑代码」审查）

## 概要

证据的组织方式比证据本身更值得质疑：多数单点排除在各自章节内是自洽的，但几乎所有排除最终都溯源到**同一个未经验证的观察**（"屏幕上是逐帧推进的循环动画"），而报告以"五级收敛"的叙述把它计成了五份独立证据。核心缺陷不在结论，而在**依赖关系没有被显式画出来**。

**跨文档核对后的追加判断（见文末「跨文档事实核对」节，第 16–20 条）**：与 `los24-build-notes.md` 及 `docs/flash-log-*.txt` 对照后，问题从"论证不严"升级为"症状归属存疑"，再升级为"**证据基座自证伪**"——报告据以建立整条等价链的「卡开机动画」，在构建笔记中只出现在 A16 blobs + A16 GKI 内核的那次构建（§27），而被报告逐字节分析的产物是 A17 内核 + A17 blobs 的构建（§32/§34）；同时那几次刷机的 `fastboot -w` 实际只擦了 metadata、没有擦 userdata，脚本却打印了「✓ userdata 已清空」。**报告继承的两条"已排除"，其原始依据是脚本的自报成功标记，而非工具输出。**

## 结论

**Request Changes（跨文档核对后从"论证需重写"升级为"起点需重定"）。**

**A. 若只看报告内部**，即使最终结论（`/data` 侧 key blob 失效）正确，当前论证方式也不成立：

1. **单点依赖被计成了多点收敛**（#1、#2）——五章共享一条未验证的观察，章节结构掩盖了这一点。
2. **两条最承重的机制都跳过了触发条件检验**（#3）——`security_patch` 是否降级、原厂是否 locked，都是离线可查的事实，报告却把前者降格为"量化"、把后者默认成最严情形。这不是证据不足，是**该问的问题没问**。
3. **可证伪条件不可执行**（#6）——挂在承重墙上的 falsifier 需要 adb，而 adb 正是缺失项。

**B. 纳入构建笔记与刷机日志后**，问题升级，且有明确的优先次序：

4. **症状与对象可能错配**（#16）——「卡开机动画」只属于 §27（A16 blobs + A16 GKI 内核）；报告分析的是 A17 构建；四次复现是四种症状且失败深度递增，最后一次甚至无日志。这是全报告最上游的断裂，**必须先解决，否则第 2–5 章全部分析都在描述另一个二进制**。
5. **时间线三段皆失守**（#17）——§31「刷前已 `-w`」否证"未 wipe"；刷机日志显示 `-w` 只擦了 metadata、没擦 userdata，脚本的 `✓ userdata 已清空` 是自报；因此 §27「清 data 后仍卡住」是**未执行的实验**，不是阴性结果。**我撤回上一轮"这是对 /data 的不利先验"的判断**，改判为 S0（实验无效）。同时新增机制 C（metadata 抹除致密文孤儿化），这是报告 A/B 两机制之外的一支。
6. **取证对象已灭失**（#18）——设备已回原厂且 /data、/metadata 被重新初始化，第 4 章全部时间线判据不可回溯；第 5 章应改写为"下一次复现前的埋点"，而非"回到现场取证"。
7. **ramoops 存在与否两说冲突**（#19）——若笔记为准，5.2 整段解释无效。
8. **继承的"已排除"未回源**（#20）——这是方法论层最重的一条：报告给自己的推论标了强弱等级，却对从 build-notes 继承来的十条"已排除"零审计，而其中至少两条建立在脚本自报成功之上。

**C. 修订顺序建议**：

① 定症状归属（#16）：为四次复现各标指纹，确认分析对象与观测症状是否同一二进制；
② 回源审计（#20）：把 build-notes §31/§33 的"已排除"逐条对原始日志核一遍，凡依据是脚本 `✓` 的降级；
③ 重写 4.3 时间线（#17）：三段皆有疑，补机制 C 与其判据；
④ 改写取证章为埋点章（#18）：先基线、再复现、后差分；
⑤ 截图比对（#2）：在**下一次复现**时执行，用于确立等价链前提；
⑥ 解决 #4（`zygote-start` 归属）→ 补 #3 两项离线核对 → 重排 #9 的候选总表。

**一句话**：前 15 条要求"把论证重写一遍"，第 16–19 条要求"先确认论证的是哪一次事故"，第 20 条要求"先确认继承来的前提是真的"。三条里**第 20 条最靠下也最致命**——报告的方法论自省（5.8 四类失效、5.9 证据分层）做得比多数工程文档都好，但它自省的对象始终是**自己写的推理**，从未自省**自己没写、直接继承的那部分证据**。它自己列的四类失效之外，实际至少还缺两类：**跨构建证据挪用**（#16）与**自报成功当工具输出**（#20）。
